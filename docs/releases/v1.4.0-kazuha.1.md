# Kazuha 1.4.0 — Windows MSIX

**Original reference: [Compositor by Robbie Tilton](https://github.com/robbietilton/Compositor).** Kazuha is an independent Windows edition based on **[Composa by Dennis van der Stelt](https://github.com/dvdstelt/Composa)**. This release builds pinned Composa 1.4.0 source with recorded Kazuha branding and the existing managed update setting. Upstream licenses and notices are preserved.

## Download

**[Download Kazuha-1.4.0-Windows-x64-MSIX.zip](https://github.com/FupaulHuang/kazuha/releases/download/v1.4.0-kazuha.1/Kazuha-1.4.0-Windows-x64-MSIX.zip)**

The complete ZIP contains eight files: `Kazuha-1.4.0-x64.msix`, `Kazuha-Local-Build.cer`, `Install-Kazuha.ps1`, `README-Kazuha.md`, `sha256sums.txt`, `LICENSE.txt`, `THIRD-PARTY-NOTICES.txt`, and `PROVENANCE.txt`. Use the complete ZIP for the installation helper.

This version displays **Kazuha** and uses the minimal autumn maple-leaf logo. It includes .NET, image codecs, and all three upstream local models. The technical executable remains `composa.exe` for compatibility. The sideload identity is `Local.Kazuha.Windows`, package version **1.4.0.0**; it is separate from the legacy Composa package and the Microsoft Store package.

## Install

Requires **Windows x64, Windows 10 version 2004 (build 19041) or later, or Windows 11**, plus administrator access for certificate trust. No developer/signing account or separate .NET installation is needed.

1. Download the ZIP and verify its SHA-256 below with `Get-FileHash .\Kazuha-1.4.0-Windows-x64-MSIX.zip -Algorithm SHA256`.
2. Extract the ZIP. Verify the MSIX and certificate against the values below and inspect `Kazuha-Local-Build.cer`. Its subject is **Kazuha Local Build**, and it expires on **23 October 2029**.
3. In the certificate dialog, choose **Install Certificate > Local Machine** and approve the administrator prompt. Choose **Place all certificates in the following store > Browse > Trusted People**, then **OK > Next > Finish**. Use **Trusted People**, not Trusted Root Certification Authorities.
4. In the intended user's ordinary desktop session, double-click `Kazuha-1.4.0-x64.msix`, choose **Install**, then open **Kazuha** from Start.

The package uses a self-signed development certificate requiring explicit manual trust. It identifies this community build, not the upstream authors' identity, and is not a publicly trusted signing identity. This download is a GitHub sideload package; it is not a Store-certified release.

For the optional helper, keep all eight files together. After verifying them, use **Properties > Unblock > Apply** if Windows marks `Install-Kazuha.ps1` as blocked. First open **Windows PowerShell** (`powershell.exe`) as administrator in the extracted folder and run the certificate-only step:

```powershell
.\Install-Kazuha.ps1 -TrustCertificate
```

It verifies the bundle and signer, displays the fingerprint, and asks for `TRUST` before adding a certificate that is not already trusted to **Local Computer > Trusted People**. This step exits without installing the app. Close the administrator window. In an ordinary, non-administrator Windows PowerShell window for the account that will use Kazuha, run:

```powershell
.\Install-Kazuha.ps1
```

This verifies the bundle again and installs for the signed-in user. It refuses an elevated session and does not change certificate trust. Neither step changes execution policy or enables Developer Mode. Organization policy may restrict sideloading.

## Verification

The Kazuha source build passed **216 selected tests**: 140 updater/application/path tests and 76 rendering, compositing, editing, history, and text tests. The full upstream suite was not run. Production Kazuha metadata and the managed update channel were checked. MakeAppx package validation and independent checks of all 244 application files, package content blocks, and signature integrity passed.

Native payload checks confirmed the Kazuha title and icon, opening and rendering the sample project, and the manual managed-update message with no release download offered. **This Kazuha MSIX has not been installation-tested, and Windows App Certification Kit results are not available.** The historical installed-Composa tests do not establish installed-Kazuha behavior. Read the [verification summary](https://github.com/FupaulHuang/kazuha/blob/v1.4.0-kazuha.1/docs/VERIFICATION.md) for scope.

## Updates, removal, and provenance

Automatic upstream GitHub checks and downloads are disabled in this build. Install later Kazuha sideload versions manually from [Kazuha releases](https://github.com/FupaulHuang/kazuha/releases). Each new signed build can have a new local certificate requiring trust. Uninstall through **Settings > Apps > Installed apps > Kazuha**. Remove its certificate from **Manage computer certificates > Trusted People** only when it is no longer needed, identifying it by the thumbprint in `PROVENANCE.txt`.
