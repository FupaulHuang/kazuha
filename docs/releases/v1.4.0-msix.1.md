# Kazuha — legacy Composa 1.4.0 MSIX release

The project is now named **Kazuha**. This historical release contains the original signed **Composa** package: its filenames, certificate subject, application title, and installed label remain unchanged. Kazuha-branded builds are being prepared separately.

**Original reference: [Compositor by Robbie Tilton](https://github.com/robbietilton/Compositor).** The Windows application is **[Composa by Dennis van der Stelt](https://github.com/dvdstelt/Composa)**. This is an unofficial MSIX repack of the unmodified [Composa v1.4.0 Windows x64 release](https://github.com/dvdstelt/Composa/releases/tag/v1.4.0), with installation helpers and verification scripts from this repository.

## Download

**[Download Composa-1.4.0-Windows-x64-MSIX.zip](https://github.com/FupaulHuang/kazuha/releases/download/v1.4.0-msix.1/Composa-1.4.0-Windows-x64-MSIX.zip)** — the recommended download, containing all eight bundle files:

The individual MSIX and certificate assets are also available for users who already have the accompanying instructions and notices. Use the complete ZIP for the installation script.

## Install with Windows dialogs

Requirements: **Windows x64, Windows 10 version 2004 (build 19041) or newer, or Windows 11**. Administrator access is needed to trust the certificate. No developer account, signing account, or separate .NET installation is required.

1. Download the ZIP and compare its SHA-256 with the value below. In PowerShell, run `Get-FileHash .\Composa-1.4.0-Windows-x64-MSIX.zip -Algorithm SHA256` from the download folder.
2. Right-click the ZIP, choose **Extract All**, and open the extracted folder. Compare the MSIX and certificate hashes with the values below, using `Get-FileHash` for each file.
3. Double-click `Composa-Local-Build.cer` and inspect the certificate. Its subject is **Composa Local Build**, it is for code signing, and it expires on **23 October 2029**. The certificate file's SHA-256 must match the release value below.
4. Choose **Install Certificate > Local Machine**, then approve the administrator prompt. Choose **Place all certificates in the following store > Browse > Trusted People**. Confirm **Trusted People**, then choose **Next > Finish**. Do not select **Trusted Root Certification Authorities**.
5. Double-click `Composa-1.4.0-x64.msix`, choose **Install**, then open **Composa (local MSIX)** from Start.

This sideload package uses a **self-signed certificate requiring manual trust**. Trusting it allows Windows to install packages signed with this certificate. It identifies this community build, not the upstream authors' identity. The release does not use a publicly trusted signing certificate and has not received Microsoft Store certification. Your organization's Windows policies may restrict installation.

### Optional PowerShell installer

Keep all eight extracted bundle files together. After verifying the ZIP and the extracted files, if Windows marks the downloaded `Install-Msix.ps1` as blocked, right-click it, choose **Properties > Unblock > Apply**. Open **Windows PowerShell** (`powershell.exe`) as administrator, change to the extracted folder, and run:

```powershell
.\Install-Msix.ps1
```

The script verifies the bundle and signer, displays the certificate fingerprint, and asks you to type `TRUST` before trusting a certificate that is not already present. It imports only that public certificate into **Local Computer > Trusted People** and then installs the MSIX. It does not change execution policy or enable Developer Mode. If scripts are restricted by policy, use the dialog workflow when your organization's policy permits installation.

## Verification and scope

Tested on Windows 11 25H2, build 26200, x64. Package integrity checks and installation passed. Eight installed workflow groups passed: startup; layer compositing; opacity and undo; transforms, duplication, painting, and text; project save/reopen and PNG export; PNG import, blur, exposure, and undo; bundled subject detection; and creation/export of an editable demonstration project. Native UI checks covered opening a project, layer duplication, undo, and redo.

See the [verification summary](https://github.com/FupaulHuang/kazuha/blob/v1.4.0-msix.1/docs/VERIFICATION.md) for scope. These checks cover selected workflows on the tested system; the full upstream test suite was not rebuilt or run for this packaging work.

## Source, licenses, and updates

The packaged application is pinned to upstream source commit [`86529d3b5355d28ddc28ec3db2e4de1d4d00f63b`](https://github.com/dvdstelt/Composa/commit/86529d3b5355d28ddc28ec3db2e4de1d4d00f63b). The repository's own additions use the MIT license; see [attribution](https://github.com/FupaulHuang/kazuha/blob/v1.4.0-msix.1/NOTICE.md).

The MSIX package version is **1.4.0.0**. The upstream app's update checker does not update this community MSIX; install later MSIX releases manually. Remove the application through **Settings > Apps > Installed apps**. When the certificate is no longer needed, remove only its matching entry from **Manage computer certificates > Trusted People**, using the thumbprint in `PROVENANCE.txt` to identify it.
